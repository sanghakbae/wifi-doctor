# 와이파이 닥터

Mac 의 Wi-Fi 를 정밀 검사하고 문제가 어디에 있는지(무선 구간인지, 공유기 너머 인터넷인지) 짚어 해결 방법을 알려 주는 무료 macOS 앱입니다.

- 소개 페이지: https://sanghakbae.github.io/wifi-doctor/
- 다운로드: [최신 DMG](https://github.com/sanghakbae/wifi-doctor/releases/latest/download/WiFiDoctor.dmg) (macOS 13 이상, 인텔·Apple 칩 겸용, Apple 공증 완료)

이 저장소는 소개 페이지와 배포 파일만 담고 있습니다.
